# declare-purpose

Read CLAUDE.md. Run `node scripts/lending.mjs declare-purpose` with the record reference the README shows. Flags: --on --actor, plus --json.

The declaration must be signed before settlement.

This changes records. Confirm the facts with the operator, pass their name in --actor, and use a code when a name matches more than one record. Nothing sends. Drafts stay in drafts/.
