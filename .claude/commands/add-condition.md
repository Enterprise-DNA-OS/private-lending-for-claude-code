# add-condition

Read CLAUDE.md. Run `node scripts/lending.mjs add-condition` with the record reference the README shows. Flags: --code --title --owner --due --actor, plus --json.

Use the wording from the loan offer.

This changes records. Confirm the facts with the operator, pass their name in --actor, and use a code when a name matches more than one record. Nothing sends. Drafts stay in drafts/.
