# add-investor

Read CLAUDE.md. Run `node scripts/lending.mjs add-investor` with the record reference the README shows. Flags: --code --name --type --email --actor, plus --json.

Retail investors cannot be allocated from this desk.

This changes records. Confirm the facts with the operator, pass their name in --actor, and use a code when a name matches more than one record. Nothing sends. Drafts stay in drafts/.
