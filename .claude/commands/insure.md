# insure

Read CLAUDE.md. Run `node scripts/lending.mjs insure` with the record reference the README shows. Flags: --expires --note --actor, plus --json.

Note where the certificate is held in --note.

This changes records. Confirm the facts with the operator, pass their name in --actor, and use a code when a name matches more than one record. Nothing sends. Drafts stay in drafts/.
