# add-security

Read CLAUDE.md. Run `node scripts/lending.mjs add-security` with the record reference the README shows. Flags: --code --address --type --actor, plus --json.

Follow with /value before the loan can settle.

This changes records. Confirm the facts with the operator, pass their name in --actor, and use a code when a name matches more than one record. Nothing sends. Drafts stay in drafts/.
