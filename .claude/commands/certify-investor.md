# certify-investor

Read CLAUDE.md. Run `node scripts/lending.mjs certify-investor` with the record reference the README shows. Flags: --on --actor, plus --json.

Use the date on the certificate itself.

This changes records. Confirm the facts with the operator, pass their name in --actor, and use a code when a name matches more than one record. Nothing sends. Drafts stay in drafts/.
