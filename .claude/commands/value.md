# value

Read CLAUDE.md. Run `node scripts/lending.mjs value` with the record reference the README shows. Flags: --market --complete --on --valuer --independent --actor, plus --json.

Ask whether the valuer is independent. Never guess a value.

This changes records. Confirm the facts with the operator, pass their name in --actor, and use a code when a name matches more than one record. Nothing sends. Drafts stay in drafts/.
